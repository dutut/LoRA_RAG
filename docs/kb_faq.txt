【问题】智云客服系统访问速度很慢怎么办？
【回答】
1. 先确认是否是局部网络问题：
   - 使用 Ping 或 Traceroute 测试本地网络到服务器的延迟。
   - 对比其他同事访问是否也很慢。
2. 登录系统「运维监控」页面，查看当前 QPS、CPU 使用率和内存占用情况。
3. 检查近期是否有大量导入历史会话或批量任务，可能会占用较多资源。
4. 如在高峰时段持续出现访问缓慢，建议联系技术支持评估是否需要扩容会话服务实例。

【问题】坐席无法登录智云客服系统，提示“账号或密码错误”怎么办？
【回答】
1. 先确认账号是否输入正确，尤其是邮箱或手机号。
2. 点击“忘记密码”尝试通过邮箱或手机号重置密码。
3. 如仍无法登录，联系企业管理员确认该账号是否已被禁用或移出当前租户。
4. 如使用 SSO 单点登录，需检查第三方身份认证服务是否正常。

【问题】为什么我看不到某些会话记录？
【回答】
1. 检查当前登录账号是否有对应会话的查看权限。
2. 在「会话记录」页面确认筛选条件是否设置过于严格，例如时间范围太短。
3. 企业管理员可以在「权限管理」中为该用户分配更高的角色权限，例如“客服主管”。
4. 如果是已删除或超出保留期的会话记录，则无法在系统中直接查看，需要联系技术支持。

【问题】如何批量导入知识库问答？
【回答】
1. 登录管理后台，进入「知识库管理」模块。
2. 下载系统提供的 Excel 模板，按格式填写问答内容。
3. 在导入页面上传 Excel 文件，系统会自动进行格式校验。
4. 对于校验失败的条目，可以导出错误报告，修正后重新导入。

【问题】如何查看某个坐席的工作量统计？
【回答】
1. 进入「数据报表-坐席分析」页面。
2. 在顶部筛选该坐席的姓名或工号。
3. 选择需要查看的时间范围，例如“近7天”或自定义时间。
4. 系统会展示接待会话数、平均响应时长、满意度等指标。
